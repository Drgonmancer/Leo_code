## 1. 数据库设计之三范式

**范式**是对设计数据库提出的规范，一般遵守 **3 范式**即可。

| 范式 | 要求 |
|------|------|
| **1NF** | 列的原子性，列不能再拆分 |
| **2NF** | 满足 1NF + 有主键 + 非主键完全依赖主键 |
| **3NF** | 满足 2NF + 非主键直接依赖主键，无传递依赖 |

### 1.1 第一范式

❌ contact 列包含多个信息 → ✅ 拆分为 name、tel、addr

### 1.2 第二范式

❌ OrderDetail 中 UnitPrice 只依赖 ProductID → ✅ 拆分为 OrderDetail + Product 两张表

### 1.3 第三范式

❌ CustomerName 通过 CustomerID 传递依赖 → ✅ 拆分为 Order + Customer

### 1.4 E-R 模型

```mermaid
erDiagram
    STUDENT ||--o{ CLASS : belongs_to
    STUDENT { int id PK string name int cls_id FK }
    CLASS { int id PK string name }
```

| 关系 | 实现 |
|------|------|
| 一对一 | 一方存另一方主键 |
| 一对多 | 「多」的一方存「一」的主键 |
| 多对多 | 中间表存双方主键 |

## 2. 外键约束

保证引用数据的有效性：

```sql
ALTER TABLE students
ADD FOREIGN KEY(cls_id) REFERENCES classes(id);
```

```sql
CREATE TABLE teacher(
    id INT NOT NULL PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(10),
    s_id INT NOT NULL,
    FOREIGN KEY(s_id) REFERENCES school(id)
);
```

删除外键：

```sql
SHOW CREATE TABLE teacher;
ALTER TABLE teacher DROP FOREIGN KEY 外键名;
```

## 3. goods 表实战

### 3.1 数据准备

```sql
CREATE DATABASE jing_dong CHARSET=utf8;
USE jing_dong;

CREATE TABLE goods(
    id INT UNSIGNED PRIMARY KEY AUTO_INCREMENT NOT NULL,
    name VARCHAR(150) NOT NULL,
    cate_name VARCHAR(40) NOT NULL,
    brand_name VARCHAR(40) NOT NULL,
    price DECIMAL(10,3) NOT NULL DEFAULT 0,
    is_show BIT NOT NULL DEFAULT 0,
    is_saleoff BIT NOT NULL DEFAULT 0
);
```

### 3.2 SQL 演练

```sql
SELECT name, price FROM goods WHERE cate_name = '超级本';
SELECT DISTINCT cate_name FROM goods;
SELECT ROUND(AVG(price), 2) FROM goods;
SELECT cate_name, ROUND(AVG(price), 2) FROM goods GROUP BY cate_name;
SELECT * FROM goods
WHERE price > (SELECT AVG(price) FROM goods)
ORDER BY price DESC;
```

**运行效果：**

```
+----------+-----------+
| cate_name| avg_price |
+----------+-----------+
| 超级本   |   5999.00 |
| 游戏本   |   8499.50 |
+----------+-----------+
```

## 4. 将查询结果插入到其他表

```mermaid
graph LR
    A[创建分类表] --> B[INSERT SELECT]
    B --> C[JOIN UPDATE]
    C --> D[ALTER 改字段]
```

```sql
CREATE TABLE good_cates(
    id INT NOT NULL PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(50) NOT NULL
);

INSERT INTO good_cates(name)
SELECT cate_name FROM goods GROUP BY cate_name;

UPDATE goods AS g
INNER JOIN good_cates AS gc ON g.cate_name = gc.name
SET g.cate_name = gc.id;
```

> 💡 `INSERT INTO ... SELECT ...` 是**表复制**；`CREATE TABLE ... SELECT ...` 是**建表并插入**。

## 6. SQL 函数

### 6.1 日期函数

```sql
SELECT NOW(), CURDATE(), CURTIME();
SELECT DATE_FORMAT(NOW(), '%Y-%m-%d %H:%i:%s');
```

| 函数 | 作用 |
|------|------|
| `NOW()` | 当前日期时间 |
| `DATE_ADD(date, INTERVAL n DAY)` | 日期加 n 天 |
| `DATEDIFF(d1, d2)` | 两日期天数差 |

### 6.2 条件函数

```sql
SELECT name, IF(age >= 18, '成年', '未成年') FROM students;

SELECT name,
    CASE gender
        WHEN '男' THEN 'Male'
        WHEN '女' THEN 'Female'
        ELSE 'Unknown'
    END AS gender_en
FROM students;

SELECT AVG(IFNULL(height, 0)) FROM students;
```

### 6.3 文本函数

```sql
SELECT CONCAT(name, '(', age, '岁)') FROM students;
SELECT UPPER(name), SUBSTRING(name, 1, 1) FROM students;
```
