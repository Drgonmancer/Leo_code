## 1. 什么是 Vim？

> 🟦 **知识卡片**
>
> **Vim** 是 Linux 上功能强大的文本编辑器，最大特色是**纯键盘操作**——完全脱离鼠标，在服务器上没有图形界面时尤其重要。

```bash
vim hello.py
```

## 2. 三种工作模式

```mermaid
stateDiagram-v2
    [*] --> 命令模式: vim 打开文件
    命令模式 --> 编辑模式: i / a / o
    编辑模式 --> 命令模式: Esc
    命令模式 --> 末行模式: :
    末行模式 --> 命令模式: Esc
```

| 模式 | 说明 | 进入方式 |
|------|------|---------|
| **命令模式** | 默认模式，移动光标、复制删除 | `vim 文件名` 打开即进入 |
| **编辑模式** | 像普通编辑器一样输入文字 | 命令模式下按 `i` |
| **末行模式** | 保存、退出、搜索替换 | 命令模式下按 `:` |

> ⚠️ **避坑**：编辑模式和末行模式**不能直接切换**，都必须先回到命令模式（按 `Esc`）。

---

## 3. 末行模式命令

| 命令 | 作用 |
|------|------|
| `:w` | 保存 |
| `:wq` | 保存并退出 |
| `:x` | 保存并退出 |
| `:q!` | 强制退出（不保存） |

```bash
vim config.py
# 编辑完成后
:wq
```

## 4. 常用编辑命令

### 4.1 复制、粘贴、删除

| 命令 | 作用 |
|------|------|
| `yy` | 复制当前行 |
| `p` | 粘贴 |
| `dd` | 删除/剪切当前行 |
| `V` | 按行选中 |
| `u` | 撤销 |
| `Ctrl+r` | 反撤销 |

### 4.2 缩进

| 命令 | 作用 |
|------|------|
| `>>` | 向右缩进 |
| `<<` | 向左缩进 |

### 4.3 搜索与替换

| 命令 | 作用 |
|------|------|
| `/搜索内容` | 搜索 |
| `:%s/旧/新/g` | 全局替换 |
| `:2,5s/旧/新/g` | 第 2~5 行局部替换 |

### 4.4 光标移动

| 命令 | 作用 |
|------|------|
| `gg` | 跳到第一行 |
| `G` | 跳到最后一行 |
| `数字+G` | 跳到指定行 |
| `Shift+6` | 当前行行首 |
| `Shift+4` | 当前行行末 |
| `Ctrl+f` | 下一屏 |
| `Ctrl+b` | 上一屏 |
| `.` | 重复上一次命令 |

## 5. 实战：编辑 Python 文件

请你按以下步骤操作：

```bash
vim hello.py
```

1. 按 `i` 进入编辑模式
2. 输入以下内容：

```python
print("Hello Vim")
```

3. 按 `Esc` 回到命令模式
4. 输入 `:wq` 保存退出
5. 运行验证：

```bash
python3 hello.py
```

**运行效果：**

```
Hello Vim
```

## 6. 记忆口诀

> 🟦 **技巧**
>
> - **打开就命令**：刚进入 Vim 是命令模式，别急着打字，先按 `i`
> - **Esc 是回家键**：不管在哪个模式，按 `Esc` 回命令模式
> - **保存三板斧**：`:w` 保存、`:wq` 保存退出、`:q!` 放弃修改
> - **删行用 dd**：比 Backspace 删一整行快得多

## 7. 本节小结

| 类别 | 核心操作 |
|------|---------|
| 模式切换 | `i` 编辑，`Esc` 回命令，`:` 末行 |
| 保存退出 | `:wq`、`:q!` |
| 编辑 | `yy` 复制、`p` 粘贴、`dd` 删除 |
| 导航 | `gg` 首行、`G` 末行、`/关键词` 搜索 |
