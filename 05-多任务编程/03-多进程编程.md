## 1. Process 类

```python
import multiprocessing
```

```mermaid
flowchart LR
    A[定义任务函数] --> B[Process 创建进程]
    B --> C[start 启动]
    C --> D[join 等待结束]
```

### 1.1 构造参数

```python
Process([group[, target[, name[, args[, kwargs]]]]])
```

| 参数 | 说明 |
|------|------|
| `group` | 进程组，目前只能用 `None` |
| `target` | 执行的目标任务函数 |
| `name` | 进程名字 |
| `args` | 元组方式传参 |
| `kwargs` | 字典方式传参 |

### 1.2 常用方法

| 方法 | 作用 |
|------|------|
| `start()` | 启动子进程 |
| `join()` | 等待子进程执行结束 |
| `terminate()` | 立刻终止子进程 |

### 1.3 常用属性

| 属性 | 说明 |
|------|------|
| `name` | 当前进程别名，默认 `Process-N` |

## 2. 创建多进程

```python
import multiprocessing
import time

def dance():
    for i in range(3):
        print('跳舞中...')
        time.sleep(0.2)

def sing():
    for i in range(3):
        print('唱歌中...')
        time.sleep(0.2)

if __name__ == '__main__':
    dance_process = multiprocessing.Process(target=dance, name='dance')
    sing_process = multiprocessing.Process(target=sing, name='sing')

    dance_process.start()
    sing_process.start()
```

**运行效果：**

```
跳舞中...
唱歌中...
跳舞中...
唱歌中...
跳舞中...
唱歌中...
```

> 📸 **截图位**：两个进程交替输出的终端界面

## 3. 获取进程编号

> 🟦 **知识卡片**
>
> 获取进程编号可以验证主进程和子进程的父子关系。

| 函数 | 作用 |
|------|------|
| `os.getpid()` | 获取当前进程编号 |
| `os.getppid()` | 获取当前父进程编号 |
| `multiprocessing.current_process()` | 获取当前进程对象 |

```python
import multiprocessing
import os
import time

def dance():
    print('子进程编号:', os.getpid())
    print('父进程编号:', os.getppid())
    for i in range(3):
        print('跳舞中...')
        time.sleep(0.2)

if __name__ == '__main__':
    print('主进程编号:', os.getpid())
    p = multiprocessing.Process(target=dance, name='dance')
    p.start()
```

**运行效果：**

```
主进程编号: 12345
子进程编号: 12346
父进程编号: 12345
跳舞中...
跳舞中...
跳舞中...
```

## 4. 进程传参

### 4.1 args 元组传参

```python
def show_info(name, age):
    print(name, age)

sub_process = multiprocessing.Process(
    target=show_info,
    args=("李四", 20)
)
```

### 4.2 kwargs 字典传参

```python
sub_process = multiprocessing.Process(
    target=show_info,
    kwargs={"name": "王五", "age": 20}
)
```

**运行效果：**

```
李四 20
```

> ⚠️ **避坑**：`args` 元组中元素顺序必须与函数参数顺序一致；`kwargs` 的 key 必须与参数名一致。

## 5. 进程注意点

### 5.1 进程之间不共享全局变量

> 创建子进程是对主进程资源的**拷贝**，子进程有自己的独立内存。

```python
import multiprocessing
import time

g_list = []

def add_data():
    for i in range(3):
        g_list.append(i)
        print('add:', i)
        time.sleep(0.2)
    print('添加完成：', g_list)

def read_data():
    print('read:', g_list)

if __name__ == '__main__':
    add_process = multiprocessing.Process(target=add_data)
    read_process = multiprocessing.Process(target=read_data)

    add_process.start()
    add_process.join()
    read_process.start()
```

**运行效果：**

```
add: 0
add: 1
add: 2
添加完成： [0, 1, 2]
read: []
```

> `read_data` 读到的是空列表——因为子进程的 `g_list` 是主进程的副本。

### 5.2 主进程等待子进程结束

主进程默认会等所有子进程执行完再退出。

```python
def task():
    for i in range(10):
        print('任务执行中...')
        time.sleep(0.2)

if __name__ == '__main__':
    sub_process = multiprocessing.Process(target=task)
    sub_process.start()
    time.sleep(0.5)
    sub_process.terminate()
    print('over')
```

**运行效果：**

```
任务执行中...
任务执行中...
任务执行中...
over
```

让主进程先退出的两种方式：

| 方式 | 代码 |
|------|------|
| 守护进程 | `sub_process.daemon = True` |
| 手动终止 | `sub_process.terminate()` |

### 5.3 `if __name__ == '__main__'`

> 🟥 **重要**：Windows 系统创建子进程时会拷贝主进程代码，不加判断会无限递归创建进程！

```python
if __name__ == '__main__':
    # 创建进程的代码写在这里
    pass
```

作用：

1. 防止别人 `import` 你的文件时执行创建进程的代码
2. 防止 Windows 无限递归创建子进程
